# Market Experiment Protocol

1. State one decision question.
2. Record the baseline and assumptions.
3. Gather current evidence; prefer primary sources.
4. Separate VERIFIED, INFERRED, UNKNOWN and BLOCKED.
5. Change one important variable where practical.
6. Define success before running the experiment.
7. Measure results and uncertainty.
8. Attack the conclusion with counterexamples and alternative explanations.
9. Record reusable evidence and update the priority queue.
10. Human approval is mandatory before consequential external action.

## Examples
- pricing: compare scenarios against explicit customer/value evidence
- positioning: test different value propositions with measurable response
- acquisition: compare channel hypotheses before automating spend/posting
- launch: identify hard blockers rather than declaring readiness from completeness
